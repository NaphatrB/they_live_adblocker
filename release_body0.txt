## Installation

Load unpacked from the `chromium/` directory, or use the zip below:

- **Chrome / Brave / Edge** — download `uBOLite_2026.529.1255.chromium.zip`, unzip, go to `chrome://extensions`, enable Developer mode, click **Load unpacked**, select the unzipped folder.
- **Firefox** — download `uBOLite_2026.529.1255.firefox.xpi`, open `about:addons`, click the gear icon → **Install Add-on From File**.

> AI classification (optional): enable in the extension settings with any OpenAI-compatible endpoint (Ollama local, ollama.com cloud, OpenAI, Groq, etc.).
